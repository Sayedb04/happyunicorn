
  # Happy Unicorn Tracker UI/UX Design

  This is a code bundle for Happy Unicorn Tracker UI/UX Design. The original project is available at https://www.figma.com/design/r6fMskQaiKC0unz58e9J7i/Happy-Unicorn-Tracker-UI-UX-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## GitHub Pages deploy

  The app is configured to build a compact static bundle into the `docs/` folder.
  You can upload or publish only that folder to GitHub Pages instead of the whole source tree.
